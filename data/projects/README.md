# 📄 ملفات بيانات المشاريع الفردية | Individual Project JSON Files

يحتوي هذا المجلد على ملف مستقل بصيغة JSON لكل مشروع في الموقع.
يمكنك فتح ملف أي مشروع وتعديل بياناته أو إضافة روابط الصور داخل مصفوفة `gallery`:

```json
"gallery": [
  "/projects/chillout-10th-of-ramadan-banks/Artboard 3.jpg",
  "/projects/chillout-10th-of-ramadan-banks/photo-1.jpg"
]
```

### 📋 قائمة ملفات المشاريع:
1. `chillout-10th-of-ramadan-banks.json` -> شيل أوت هب – العاشر من رمضان (مركز البنوك)
2. `chillout-10th-of-ramadan-alrowad.json` -> شيل أوت هب – العاشر من رمضان (نادي الرواد)
3. `chillout-mostafa-kamel.json` -> شيل أوت هب – محور مصطفى كامل
4. `chillout-marina-5.json` -> شيل أوت هب – مارينا 5
5. `sour-nady-el-nady.json` -> سور نادي النادي
6. `sour-nady-el-obour.json` -> سور نادي العبور
7. `el-salam-plaza-mall.json` -> مول السلام بلازا

💡 **ملاحظة ذكية**:
إذا وضعت الصور مباشرة داخل مجلد المشروع في `public/projects/[id]/`، سيتعرف عليها الموقع تلقائياً دون الحاجة لتعديل أي ملف!
