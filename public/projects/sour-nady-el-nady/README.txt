📌 كيفية إضافة صور لهذا المشروع:
1. انسخ أو اسحب أي صور تريدها داخل هذا الفولدر مباشرة.
2. الصيغ المدعومة: JPG, PNG, WEBP, JPEG.
3. ستظهر كل الصور تلقائياً داخل معرض صور المشروع في الموقع!
4. لتحديد صورة الغلاف الرئيسي للصفحة، يمكنك تسميتها: cover.jpg
5. لإضافة فيديو للمشروع، يمكنك تسميته: video.mp4

=====================================================================
How to add photos for this project:
1. Drop any photos directly into this folder.
2. Supported formats: .jpg, .png, .webp, .jpeg.
3. All photos will automatically appear in the project gallery!
4. To set a custom cover, name it: cover.jpg
